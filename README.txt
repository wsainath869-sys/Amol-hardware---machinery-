AMOL HARDWARE AND MACHINERY WEBSITE

Files:
- index.html: website content
- style.css: styling and mobile responsive layout
- script.js: mobile navigation and current year

Publish free with GitHub Pages:
1. Upload ALL files in this folder to the ROOT of a PUBLIC GitHub repository.
2. Open repository Settings > Pages.
3. Under Build and deployment choose "Deploy from a branch".
4. Select branch "main" and folder "/ (root)", then Save.
5. Wait for deployment and open the URL shown on the Pages screen.

Before publishing, confirm the shop's exact address and whether the phone numbers and product list are correct.
